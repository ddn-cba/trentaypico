# TrentaYPico

Sitio estático, sin dependencias ni paso de compilación.

1. Descomprimí el ZIP y subí su contenido a la raíz del repositorio, incluido el archivo oculto `.nojekyll`.
2. En GitHub, abrí **Settings → Pages**.
3. Elegí **Deploy from a branch**, seleccioná **main** y **/ (root)**. Guardá y abrí la URL que GitHub muestre en Pages.
